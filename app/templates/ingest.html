Data Ingestion

Batch upload (historical or recent)

Formats: CSV, TXT, JSON, Excel, Parquet, NetCDF (.nc). Required columns: station_id, date. Any of the 12 climate metrics may be present; missing ones are imputed. Station metadata is filled from the station registry.

Real-time sources

REST API – POST JSON (one object or a list) to /api/ingest with header X-API-Key.

curl -X POST http://127.0.0.1:5000/api/ingest -H "X-API-Key: earthscape-demo-key" -H "Content-Type: application/json" -d "{\"station_id\":\"ST01\",\"date\":\"2024-07-01\",\"temperature_c\":44.5,\"wind_speed_kmh\":20}"

Sensor simulator – python simulator.py --rate 2 --batch 12

Built-in live stream – button on the Dashboard. Production: Kafka → Spark Structured Streaming (see hadoop/).
