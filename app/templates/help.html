Quick tutorial
  1. Open the Dashboard and start the live sensor stream.
  2. Watch new readings, forecasts and alert pop-ups.
  3. Open Map to see stations coloured by any metric.
  4. Use Explore to compare stations and view correlations.
  5. Run a scenario on Predict and read the "Why?" table.
  6. Upload testing_dataset.csv on Ingestion and see the model retrain on Models.
